
# Retail Analytics Platform

## Project Overview
An end-to-end retail sales analytics project focused on analyzing sales, profit, customers, products, and regional business performance.

## Technologies Used
- Python
- Pandas
- SQL
- SQLite
- Microsoft Power BI

## Project Structure
- `src/` - Python scripts for data inspection, cleaning, and analysis.
- `sql/` - SQL queries for business analysis.
- `data/` - Local datasets and database files (not included in this repository).
- `reports/` - Power BI reports (not included in this repository).

## Key Objectives
- Clean and validate retail sales data.
- Perform exploratory data analysis.
- Analyze business performance using SQL.
- Build interactive Power BI dashboards.
